# Scanner-nmap-rus-
# Port Scanner & Vulnerability Checker

Простое консольное приложение для сканирования открытых портов и проверки их на уязвимости.

## 📌 Описание

Инструмент выполняет три основные функции:

1. **Сканирование портов**:
   - Обнаружение всех открытых портов на локальной машине
   - Определение сервисов, работающих на этих портах

2. **Проверка уязвимостей**:
   - Анализ найденных портов на известные уязвимости
   - Проверка конфигураций безопасности

3. **Формирование отчёта**:
   - Детальный список всех обнаруженных проблем

## ⚙️ Установка

1. Установите **Nmap** (обязательное требование):
   ```bash
   # Для Windows:
   https://nmap.org/download.html

   # Для Linux (Debian/Ubuntu):
   sudo apt install nmap
   ```

2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Z0ro321/Scanner-nmap-rus-.git
   ```

## 🖥️ Использование

После запуска следуйте инструкциям в консольном меню (интерфейс на русском языке). Программа предложит:

1. Выполнить сканирование
2. Просмотреть предыдущие результаты
3. Экспортировать отчёт
4. Выход
